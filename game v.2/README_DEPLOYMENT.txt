🌐 วิธีเอาเกมขึ้นเว็บเพื่อแชร์ลิงก์ให้เพื่อนเล่น
================================================

📌 วิธีที่ 1: Netlify Drop (ง่ายที่สุด ไม่ต้องสมัคร!)
--------------------------------------------------
1. เปิดเว็บ: https://app.netlify.com/drop
2. ลากไฟล์ "game.html" วางในกล่อง
3. รอ 5-10 วินาที
4. คัดลอกลิงก์ที่ได้ เช่น: https://your-game-123abc.netlify.app
5. แชร์ลิงก์ให้เพื่อนได้เลย!

✅ ข้อดี: ไม่ต้องสมัคร ใช้งานฟรี รวดเร็ว
❌ ข้อเสีย: ลิงก์จะเป็นชื่อสุ่ม แก้ไขไฟล์ต้อง upload ใหม่

---

📌 วิธีที่ 2: GitHub Pages (แนะนำถ้าต้องการแก้ไขบ่อย)
----------------------------------------------------
1. สมัคร GitHub: https://github.com/signup
2. สร้าง Repository ใหม่: https://github.com/new
   - ตั้งชื่อ: typing-craft-game
   - เลือก Public
   - Create repository

3. Upload ไฟล์:
   - คลิก "uploading an existing file"
   - เปลี่ยนชื่อ "game.html" เป็น "index.html"
   - ลากไฟล์ index.html วางในกล่อง
   - Commit changes

4. เปิดใช้ GitHub Pages:
   - Settings > Pages
   - Source: main branch
   - Save
   - รอ 1-2 นาที

5. ลิงก์เกม: https://your-username.github.io/typing-craft-game/

✅ ข้อดี: แก้ไขได้ง่าย มีประวัติการแก้ไข ชื่อลิงก์กำหนดเองได้
❌ ข้อเสีย: ต้องสมัคร GitHub

---

📌 วิธีที่ 3: Vercel
--------------------
1. สมัคร: https://vercel.com (ใช้ GitHub login)
2. คลิก "Add New" > "Project"
3. Import โฟลเดอร์ที่มีไฟล์ game.html
4. Deploy
5. ได้ลิงก์เช่น: https://typing-craft.vercel.app

✅ ข้อดี: รวดเร็ว อัพเดทอัตโนมัติ
❌ ข้อเสีย: ต้องสมัคร

---

📌 วิธีที่ 4: Render
--------------------
1. สมัคร: https://render.com
2. New > Static Site
3. Connect GitHub หรือ Upload ไฟล์
4. Deploy
5. ได้ลิงก์ฟรี

---

💡 คำแนะนำ:
- ถ้าต้องการ upload เดี๋ยวนี้เลย → ใช้ Netlify Drop
- ถ้าต้องการแก้ไขเกมบ่อยๆ → ใช้ GitHub Pages
- ทุกวิธีใช้ฟรี 100%!
